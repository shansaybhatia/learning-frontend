## 📂 What's Here So Far

### 01basicreact — Create React App

A starter project scaffolded with [Create React App](https://create-react-app.dev/).

- **Stack:** React 19.3.0, React DOM 19.3.0
- **Key files:** `App.js`, `index.js`, `Welcome.js`

```bash
cd 01basicreact
npm install
npm start
```

### 01viteReact — Vite + React

A starter project scaffolded with [Vite](https://vite.dev/).

- **Stack:** React 19.2.8, React DOM 19.2.8, Vite 8.3.0
- **Key files:** `App.jsx`, `main.jsx`, `welcome.jsx`

```bash
cd 01viteReact
npm install
npm run dev
```
