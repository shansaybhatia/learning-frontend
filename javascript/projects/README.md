# ⚡ JavaScript Mini-Projects Suite

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

A collection of 6 hands-on JavaScript mini-projects designed to master real-world DOM manipulation, event handling, timers, and mathematical calculation logic. All projects can be launched from the shared interactive hub `index.html`.

---

## 🚀 Projects Overview

| # | Project | Key Concepts Practiced | Description |
|---|---|---|---|
| **01** | [**Color Changer**](./1-colorChanger/) | `addEventListener`, `e.target.id`, `style.backgroundColor` | Click on color chips (grey, white, blue, yellow) to dynamically change the canvas background color. |
| **02** | [**BMI Calculator**](./2-bmiCalculator/) | Form handling, `parseInt`, math calculations, DOM results injection | Enter height (cm) and weight (kg) to calculate Body Mass Index and display weight status categories. |
| **03** | [**Digital Clock**](./3-DigitalClock/) | `setInterval`, `new Date().toLocaleTimeString()` | Real-time digital clock updating every 1000ms with custom banner styling. |
| **04** | [**Guess the Number**](./4-guessNumber/) | Random number generation (`Math.random`), game state, remaining attempts | Guess a secret number between 1 and 100 with live hint alerts ("too high" or "too low") and a 10-attempt limit. |
| **05** | [**Keyboard Check**](./5-keyboard/) | `window.addEventListener('keydown')`, `e.key`, `e.keyCode`, `e.code` | Real-time keyboard event inspector displaying the pressed key, numerical keycode, and physical key code in a table. |
| **06** | [**Unlimited Colors**](./6-unlimitedColors/) | `setInterval`, `clearInterval`, random hex color generator | Start and stop buttons controlling continuous asynchronous color transitions. |

## ▶️ Getting Started

Open the central launcher in your browser:

```bash
# From the repository root:
open javascript/projects/index.html   # macOS
start javascript/projects/index.html  # Windows
```

Or simply double-click `javascript/projects/index.html` to access all 6 projects with one click!
