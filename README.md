## 📖 About

This is my personal learning repository where I work through frontend development topics — from the basics of HTML all the way to React and TypeScript. It contains structured lessons, tutorial-based projects, and small apps I've built along the way. Nothing fancy, just honest practice.

---

## 🛠️ Technologies & Topics

| Technology | What's Covered |
|---|---|
| **HTML** | Document structure, semantic elements, tables, forms, media |
| **CSS** | Selectors, box model, flexbox, grid, animations, responsive design |
| **JavaScript** | Fundamentals, DOM manipulation, events, async/await, mini projects |
| **Bootstrap + Sass** | Component-based layouts, custom theming with Sass variables & mixins |
| **React** | Component architecture, JSX, Vite & CRA tooling *(in progress)* |
| **TypeScript** | Type annotations, interfaces, generics, React + TypeScript integration |

## 🎯 Learning Goals

This repository reflects an ongoing learning journey — not a finished product. The goals are simple:

- Build a solid understanding of core frontend technologies
- Practice by building real (if small) projects
- Get comfortable with modern tooling like Vite, Sass, and TypeScript
- Eventually become confident with React and component-driven development

Some sections are more complete than others, and that's okay.
