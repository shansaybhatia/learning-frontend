# 🎨 CSS

**Learning CSS — from colors and typography to animations and responsive layouts.**

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

This folder contains progressive CSS exercises and projects that build on the HTML foundations, covering everything from basic styling to advanced layout systems.

---

## 📚 Lessons

### Fundamentals (01–04)

| # | Lesson | Topic |
|---|--------|-------|
| 01 | **Font_Colors** | Fonts, color values, and color properties |
| 02 | **Units_Sizes** | CSS units — `px`, `em`, `rem`, `%`, `vh`/`vw` |
| 03 | **BoxModel** | Margin, padding, border, and the box model |
| 04 | **Typography** | Font families, line height, and text styling |

### Styling & Navigation (05–06)

| # | Lesson | Topic |
|---|--------|-------|
| 05 | **Styling_Links** | Link states, hover effects, and navigation styling |
| 06 | **List_Styling** | Custom list markers and styled lists |

### Layout Systems (07–12)

| # | Lesson | Topic |
|---|--------|-------|
| 07 | **Display** | The `display` property — block, inline, inline-block, none |
| 08 | **Floats** | Float-based layouts and clearing |
| 09 | **Columns** | Multi-column layouts with CSS columns |
| 10 | **Position** | Positioning — `relative`, `absolute`, `fixed`, `sticky` |
| 11 | **Flexbox** | Flexible box layout for one-dimensional alignment |
| 12 | **GridLayout** | CSS Grid for two-dimensional page layouts |

### Responsive & Visual (13–16)

| # | Lesson | Topic |
|---|--------|-------|
| 13 | **Images** | Image styling and responsive images |
| 14 | **MediaQueries** | Responsive design with media queries |
| 15 | **CardProject** | Building a reusable card component |
| 16 | **PseudoClass** | Pseudo-classes and pseudo-elements |

### Advanced (17–20)

| # | Lesson | Topic |
|---|--------|-------|
| 17 | **Variables** | CSS custom properties (variables) |
| 18 | **Functions** | CSS functions — `calc()`, `clamp()`, `min()`, `max()` |
| 19 | **Animations** | Transitions and keyframe animations |
| 20 | **Organizations** | CSS file organization and architecture |

## 🚀 Projects

| [College Website](./projects/college-website/) | Styled version of the HTML college website with full CSS |

## 🖥️ How to Run

Open any `.html` file directly in your browser. The Taco Shop project includes a small JavaScript file (`js/main.js`) for the theme toggle — no other build tools needed.
