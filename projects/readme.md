## 🛠️ Engineering Standards Across Projects

Every application in this directory adheres to modern frontend best practices:

- **📱 Mobile-First Design:** Fluid responsiveness crafted from 320px viewport upwards using modern CSS Grid, Flexbox, and `clamp()`.
- **♿ First-Class Accessibility (a11y):** Semantic markup, WCAG-compliant color contrast, visible focus rings, keyboard navigability, and dynamic `aria-live` regions for assistive technologies.
- **⚡ Zero Bloat:** Clean, maintainable code written with modular Vanilla JavaScript (OOP or functional) and modular Sass before introducing heavy frameworks.
- **💾 Persistence:** Seamless local client-side persistence with robust fallback handling.
